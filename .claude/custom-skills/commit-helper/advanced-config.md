# Advanced Configuration

## Breaking Changes

When making breaking changes, mention it explicitly:

```
Generate commit message: Removed legacy API endpoints (breaking change)
```

The skill will add appropriate BREAKING CHANGE footer.

## Issue References

Link to issue trackers:

```
Create commit: Fixed memory leak in cache system
Issues: PROJ-123, PROJ-124
```

## Custom Scopes

Suggest specific component scopes:

```
Generate commit for authentication module changes
Scope: auth
Type: refactor
```

## Multi-Component Changes

For changes spanning multiple areas:

```
Create commit message for:
- Updated dependencies
- Refactored error handling
- Added logging
```
